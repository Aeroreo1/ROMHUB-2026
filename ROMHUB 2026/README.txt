# ROMHUB

ROMHUB is a C# WPF desktop application for organising and managing a personal ROM library and configured emulators.

## Features

- Add and manage ROMs
- Organise ROMs by platform
- Configure emulator locations
- Launch ROMs using configured emulators
- Persistent library data
- Windows desktop interface

## Requirements

- Windows 10 or Windows 11
- 64-bit Windows

The distributed application is published as self-contained, so users do not need Visual Studio or a separate .NET installation to run it.

## Installation

1. Download the latest ROMHUB release.
2. Extract the ZIP file.
3. Run `ROMHUB_2026.exe`.

## Usage

Configure your emulator locations and add your ROM files to the library.

ROMHUB does not include ROM files or BIOS files. Users are responsible for obtaining and using their own legally obtained files.
